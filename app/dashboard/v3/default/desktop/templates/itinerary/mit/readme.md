# MIT Multi-Page Proposal Template

- **ID**: `mit`
- **Name**: MIT Proposal
- **Tag**: Default
- **Badge**: Multi-Page
- **Accent Color**: `#ea580c`
- **Format**: Dynamic multi-page A4 PDF proposal with wave hero headers, hotel stay summaries, side-by-side inclusion/exclusion cards, company contact page, and responsive web proposal layout.

## Features
- Dynamic hero banner with wave bottom mask
- Quick statistics grid (Duration, Theme, Hotel, Vehicle)
- Detailed Day-Wise Itinerary cards with sightseeing photos
- Overnight stay cards and conclusion/farewell card
- Dual-column Inclusions & Exclusions block
- Dedicated Company Contact card with dynamic site details
- Aleya credit footer note
