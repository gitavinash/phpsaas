# WhatsApp Cloud API & Notify360 Engine

## Overview
Connect official Meta WhatsApp Business Cloud API to deliver interactive travel itineraries, automatic booking confirmations, payment request links, and customized quotations with zero third-party markups.

## Technical Specifications
- **Plugin Identifier**: `whatsapp`
- **Category**: Messaging & Chat
- **API Provider**: Meta WhatsApp Cloud API / Notify360
- **Webhook Endpoint**: `https://yourdomain.com/webhook/whatsapp/`

## Key Capabilities
- **Rich Interactive Messages**: Send message templates with quick-reply buttons, call-to-actions, and PDF attachments.
- **Automated Milestone Triggers**:
  - New Inquiry auto-reply & welcome brochure.
  - Booking payment receipts & instant voucher links.
  - Customized travel itinerary PDF dispatches.
- **Enterprise Scale**: High-throughput message queuing and real-time delivery status reports.
