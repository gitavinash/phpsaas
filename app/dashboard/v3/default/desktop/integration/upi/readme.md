# UPI & Dynamic QR Code Integration

## Overview
Generate NPCI standard Unified Payments Interface (UPI) dynamic QR codes formatted directly for customer quotations, tour vouchers, and invoices with 0% gateway transaction surcharge.

## Technical Specifications
- **Plugin Identifier**: `upi`
- **Category**: Payments & Banking
- **QR Standard**: NPCI BharatQR / UPI Deep Linking (`upi://pay`)
- **Supported Payment Apps**: Google Pay, PhonePe, Paytm, BHIM, Cred, Amazon Pay, All Bank UPI Apps

## Features
- **Dynamic Amount Encoding**: Embeds exact booking advance or balance payable amounts into the scanned QR code.
- **Payee Verification**: Pre-fills the official Merchant / Business Name so travelers know they are remitting to the legitimate agency.
- **Direct Settlement**: Funds settle immediately into your primary current bank account with no middleman delays.
