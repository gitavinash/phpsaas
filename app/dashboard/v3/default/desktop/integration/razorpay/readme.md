# Razorpay Payment Gateway Integration

## Overview
Accept credit/debit cards, Netbanking from 50+ banks, UPI, and PayLater with automated booking payment reconciliation and instant receipt generation.

## Technical Specifications
- **Plugin Identifier**: `razorpay`
- **Category**: Payments & Banking
- **Webhook Endpoint**: `https://yourdomain.com/webhook/razorpay/`
- **Supported Currencies**: INR, USD, EUR, GBP, AED, SGD

## Capabilities
- **Dynamic Payment Links**: Generate tokenized payment links with customizable partial advance amounts.
- **Webhook Auto-Reconciliation**: Marks booking payments as Paid automatically upon successful capture.
- **Live / Test Sandbox**: Safely test booking payments in Sandbox before switching to Production keys.
